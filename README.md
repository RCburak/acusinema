# AcuSinema Cinema Management System

## Overview
AcuSinema is a complete cinema management system designed to streamline operations for cinemas. With its user-friendly interface and robust features, it allows cinemas to manage their schedules, bookings, and customer relations effectively.

## Features
- **Ticket Booking**: Easy online booking system for customers.
- **Schedule Management**: Manage movie schedules and timings effortlessly.
- **Customer Management**: Keep track of customer information and booking history.
- **Reporting**: Generate reports for sales and customer data.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/RCburak/acusinema.git
   ```
2. Navigate to the project directory:
   ```bash
   cd acusinema
   ```
3. Install the required dependencies:
   ```bash
   npm install
   ```

## Usage
To start the application, run:
```bash
npm start
```
Open your browser and go to `http://localhost:3000` to access the AcuSinema dashboard.
